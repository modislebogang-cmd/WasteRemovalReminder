# Phase 2 Quick Start Guide

## Switching Roles
1. Look for the role dropdown in the top-right corner of the header
2. Select **Staff** or **Manager**
3. The UI will update to show role-specific features

## Advanced Filtering (Products Tab)
1. Navigate to **Products** tab
2. Use the three dropdown filters below the search bar:
   - **Status**: Expired, Remove Today, Upcoming (7 days), Safe (8+ days)
   - **Category**: Filter by product category
   - **Expiry Range**: 0-3 days, 4-7 days, 8+ days
3. Filters can be combined for powerful searches
4. Click dropdown again and select "All ___" to clear a filter

## CSV Export (Manager Only)
1. Switch to **Manager** role
2. Go to **Products** tab
3. (Optional) Apply filters to export only specific products
4. Click **Export CSV** button
5. File downloads as `products_YYYY-MM-DD.csv`
6. Open in Excel, Google Sheets, or any spreadsheet application

## In-App Notifications
- **Dashboard**: Look for alert banner below the header when products need removal
- Shows count of products that are expired or due today
- Click the **×** button to dismiss the notification
- Reappears automatically when new products expire

## Category Management (Manager Only)
1. Switch to **Manager** role
2. Go to **Settings** tab
3. Scroll down to "Manage Categories" section
4. **View categories**: Current categories are listed
5. **Add category**: Type name in input field, click "Add"
6. **Remove category**: Click trash icon next to category
7. Changes save automatically

## Activity Log (Manager Only)
1. Switch to **Manager** role
2. Look for **Activity** tab in bottom navigation (appears only for managers)
3. View complete audit trail showing:
   - **Time**: When action occurred
   - **User**: Who performed the action
   - **Action**: What was done
   - **Details**: Specific information about the action
4. Latest activities appear first
5. Log maintains last 1000 actions

## Staff vs Manager Capabilities

### Staff Roles Can:
- ✅ Scan product barcodes
- ✅ Add products manually
- ✅ View all products
- ✅ Mark products as removed
- ✅ Search and filter products
- ✅ Set personal name and manage own settings

### Manager Roles Can:
- ✅ Everything Staff can do, PLUS:
- ✅ Export products to CSV
- ✅ Manage product categories
- ✅ View complete activity log of all users
- ✅ See who did what and when

## Tips & Tricks

### Filtering Tips
- Combine multiple filters to find exactly what you need
- Use "Remove Today" + "Expired" status to see urgent products
- Filter by category to check specific sections

### Export Tips
- Filter first, then export to get only relevant data
- Export regularly for compliance/backup
- Exports include timestamp and manager name

### Activity Tips
- Use activity log to identify staff patterns
- Check activity when inventory doesn't match
- Monitor peak scanning times

### Data Persistence
- All data saves automatically to browser storage
- Settings, categories, and activity persist after closing browser
- Each browser/device maintains separate data
- Clear browser cache to reset data

## Troubleshooting

**Role selector not changing?**
- Hard refresh the page (Ctrl+Shift+R on Windows)
- Check browser console for errors

**CSV file won't open?**
- Make sure spreadsheet app is installed
- Try opening as CSV format in Excel

**Activity not showing?**
- Must be logged in as Manager
- Log entries may be cleared if browser cache is cleared

**Filters not working?**
- Reload the page
- Try refreshing Products tab
- Ensure products exist in that filter category
